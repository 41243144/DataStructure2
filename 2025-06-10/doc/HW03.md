## 解答

### (a) DFS 與 BFS 遍歷

#### DFS (Depth-First Search) 從節點 2 開始
**遍歷順序：** 2 → 1 → 4 → 5 → 3 → 6

**說明：**
- 從節點 2 開始
- 選擇編號較小的相鄰節點 1
- 從節點 1 到編號較小的未訪問節點 4
- 從節點 4 到節點 5
- 從節點 5 到節點 3
- 最後訪問節點 6

#### BFS (Breadth-First Search) 從節點 2 開始
**遍歷順序：** 2 → 1 → 3 → 4 → 5 → 6

**說明：**
- 從節點 2 開始
- 第一層：訪問節點 2 的所有鄰居 {1, 3, 4, 5}，按編號排序為 1, 3, 4, 5
- 第二層：從這些節點中訪問未訪問的鄰居，得到節點 6

### (b) Kruskal's Algorithm

#### 算法描述
```
Kruskal's Algorithm:
1. 將所有邊按權重由小到大排序
2. 初始化：每個節點自成一個集合
3. For each edge (u,v) in sorted order:
   a. 如果 u 和 v 不在同一個集合中
   b. 將邊 (u,v) 加入 MST
   c. 合併 u 和 v 所在的集合
4. 重複直到 MST 包含 n-1 條邊
```

#### Step by Step 執行過程

**Step 1: 邊排序**
按權重排序所有邊：
1. (1,2): 10
2. (6,3): 15  
3. (4,6): 20
4. (4,5): 25
5. (1,4): 30
6. (5,3): 35
7. (2,5): 40
8. (2,4): 45
9. (2,3): 50
10. (5,6): 55

**Step 2: 執行 Kruskal 算法**

| 步驟 | 檢查邊 | 權重 | 動作 | MST邊 | 集合狀態 |
|------|---------|------|------|-------|----------|
| 初始 | - | - | - | {} | {1},{2},{3},{4},{5},{6} |
| 1 | (1,2) | 10 | 加入 | {(1,2)} | {1,2},{3},{4},{5},{6} |
| 2 | (6,3) | 15 | 加入 | {(1,2),(6,3)} | {1,2},{3,6},{4},{5} |
| 3 | (4,6) | 20 | 加入 | {(1,2),(6,3),(4,6)} | {1,2},{3,6,4},{5} |
| 4 | (4,5) | 25 | 加入 | {(1,2),(6,3),(4,6),(4,5)} | {1,2},{3,6,4,5} |
| 5 | (1,4) | 30 | 加入 | {(1,2),(6,3),(4,6),(4,5),(1,4)} | {1,2,3,4,5,6} |

**最小生成樹總權重：** 10 + 15 + 20 + 25 + 30 = 100

### (d) Kruskal vs Prim 算法比較

#### 時間複雜度比較

| 算法 | 時間複雜度 | 適用情況 |
|------|------------|----------|
| **Kruskal** | O(E log E) | 稀疏圖 (E << V²) |
| **Prim** | O(V²) 或 O(E log V) | 稠密圖 (E ≈ V²) |

#### 詳細分析

**Kruskal's Algorithm:**
- 排序邊：O(E log E)
- Union-Find 操作：O(E α(V)) ≈ O(E)
- 總時間複雜度：O(E log E)

**Prim's Algorithm:**
- 使用陣列：O(V²)
- 使用二元堆積：O(E log V)
- 使用費氏堆積：O(E + V log V)

#### 何者較佳？

- **稀疏圖 (E << V²)**：Kruskal 較佳
- **稠密圖 (E ≈ V²)**：Prim 較佳
- **實作簡易度**：Kruskal 較簡單
- **記憶體使用**：Prim 較節省（不需存儲所有邊）

### (e) 理論證明

**命題：** 圖形 G 的任兩個 minimal spanning trees 必存在相同的 edge。

**答案：** False (錯誤)

**反例證明：**

考慮以下簡單圖形：
```
    A ----1---- B
    |           |
    2           2  
    |           |
    C ----1---- D
```

**MST 1:** 選擇邊 {(A,B), (A,C), (C,D)}，總權重 = 4
**MST 2:** 選擇邊 {(A,B), (B,D), (C,D)}，總權重 = 4

這兩個 MST 只有共同邊 (A,B) 和 (C,D)，但 MST1 包含 (A,C) 而 MST2 包含 (B,D)。

**結論：** 
- 不同的 MST 可能包含不同的邊
- 但所有 MST 的總權重必定相同
- 當圖中存在權重相同的邊時，可能產生多個不同的 MST

## 算法實作重點

### DFS 實作要點
```cpp
void dfs(int node, vector<vector<int>>& adj, vector<bool>& visited) {
    visited[node] = true;
    cout << node << " ";
    
    // 按節點編號排序訪問
    for (int neighbor : adj[node]) {
        if (!visited[neighbor]) {
            dfs(neighbor, adj, visited);
        }
    }
}
```

### BFS 實作要點
```cpp
void bfs(int start, vector<vector<int>>& adj) {
    vector<bool> visited(adj.size(), false);
    queue<int> q;
    
    q.push(start);
    visited[start] = true;
    
    while (!q.empty()) {
        int node = q.front();
        q.pop();
        cout << node << " ";
        
        // 按節點編號排序訪問
        for (int neighbor : adj[node]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
}
```

### Union-Find 實作要點
```cpp
class UnionFind {
    vector<int> parent;
public:
    UnionFind(int n) : parent(n) {
        for (int i = 0; i < n; i++) parent[i] = i;
    }
    
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]); // 路徑壓縮
        }
        return parent[x];
    }
    
    bool unite(int x, int y) {
        int rootX = find(x), rootY = find(y);
        if (rootX == rootY) return false;
        
        // 較小根合併到較大根
        if (rootX < rootY) parent[rootX] = rootY;
        else parent[rootY] = rootX;
        
        return true;
    }
};
```
