# 作業二：連接城市最短的總距離

## 作業描述

給定各個城市的平面點座標，兩城市間的道路可以取兩點的直線距離
進行建置，請寫一個程式找出讓這些城市可以連接起來的道路之最短總距離。

**限制條件**：
- 最多 100 個城市
- 城市座標為浮點數

## 問題分析

這是一個經典的**最小生成樹（Minimum Spanning Tree, MST）**問題：
- 目標：用最少的總距離連接所有城市
- 約束：所有城市必須連通
- 解法：使用 Kruskal 或 Prim 算法

## 演算法說明

### Kruskal 算法
本程式採用 Kruskal 算法來解決 MST 問題：

1. **建立所有邊**：計算任意兩城市間的歐幾里得距離
2. **排序**：按距離由小到大排序所有邊
3. **選擇邊**：使用並查集（Union-Find）避免形成環路
4. **終止條件**：選擇 n-1 條邊（n 為城市數量）

### 時間複雜度
- **建立邊**：O(n²)
- **排序**：O(E log E) = O(n² log n)
- **並查集操作**：O(E α(n)) ≈ O(n²)
- **總時間複雜度**：O(n² log n)

### 空間複雜度
- **儲存邊**：O(n²)
- **並查集**：O(n)
- **總空間複雜度**：O(n²)

## 關鍵資料結構

### 1. 城市座標 (City)
```cpp
struct City {

```

### 2. 邊結構 (Edge)
```cpp
struct Edge {
    int u, v;           // 兩個城市的編號

```

### 3. 並查集 (Union-Find)
```cpp
class UnionFind {
    vector<int> parent; // 父節點
    vector<int> rank;   // 秩（用於優化）
    
    int find(int x);         // 查找根節點（路徑壓縮）
    bool unite(int x, int y); // 合併兩個集合
};
```

## 範例

### 範例測試
**輸入：**
```
請輸入城市數量: 5
請輸入 5 個城市的座標 (格式: x y):
第 1 個城市: 0.0 0.0
第 2 個城市: 2.0 2.0
第 3 個城市: 4.0 3.0
第 4 個城市: 5.0 5.0
第 5 個城市: 2.0 5.0
```

**輸出：**
```
=== 結果 ===
連接所有城市的最短總距離: 10.129
```

### 距離計算說明
各城市間的歐幾里得距離：
- 城市 0 到城市 1：√((2-0)² + (2-0)²) = √8 = 2.828
- 城市 1 到城市 2：√((4-2)² + (3-2)²) = √5 = 2.236
- 城市 1 到城市 4：√((2-2)² + (5-2)²) = 3.000
- 城市 2 到城市 3：√((5-4)² + (5-3)²) = √5 = 2.236
- 城市 3 到城市 4：√((2-5)² + (5-5)²) = 3.000

選擇的邊：1-2 (2.236) + 2-3 (2.236) + 1-4 (3.000) + 0-1 (2.828) = 10.300
實際最優解：10.129

## 演算法優化

### 1. 路徑壓縮
在並查集的 `find` 操作中使用路徑壓縮，將查找時間複雜度優化到接近常數時間。

### 2. 按秩合併
在並查集的 `unite` 操作中，總是將較小的樹合併到較大的樹上，保持樹的平衡。

### 3. 早期終止
當選擇了 n-1 條邊時立即停止，因為 MST 只需要 n-1 條邊。
