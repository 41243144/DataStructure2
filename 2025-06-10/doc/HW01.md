# 作業一：圖的連通分量分析

## 作業描述

G=[V,E]是一個無向圖形，請寫一個程式找出所給定之無向圖之 maximal connected components。
// 總共不超過 100 個點, 設節點編號從 0 開始, 為連續

## 程式功能

1. **輸入驗證**：檢查節點數量和邊數量的有效性
2. **圖建構**：建立無向圖的鄰接表表示法
3. **連通分量搜尋**：使用 DFS 尋找所有連通分量
4. **結果分析**：統計連通分量數量並找出最大的連通分量

## 演算法說明

### 深度優先搜尋（DFS）
- **時間複雜度**：O(V + E)，其中 V 是節點數，E 是邊數
- **空間複雜度**：O(V)，用於存儲訪問狀態和遞迴堆疊
- **原理**：從未訪問的節點開始，遞迴訪問所有相連的節點

### 連通分量分析
1. 初始化所有節點為未訪問狀態
2. 對每個未訪問的節點執行 DFS
3. 每次 DFS 的結果就是一個連通分量
4. 記錄所有連通分量並找出最大的

## 輸入格式

```
請輸入節點數量和邊數量: n m
請輸入 m 條邊 (格式: u v):
第 1 條邊: u1 v1
第 2 條邊: u2 v2
...
第 m 條邊: um vm
```

### 輸入說明
- `n`：節點數量（必須為正數）
- `m`：邊數量（不能為負數）
- `u v`：表示節點 u 和節點 v 之間有一條邊
- 節點編號範圍：0 到 n-1

## 輸出格式

```
=== 結果 ===
總共有 X 個連通分量
最大連通分量包含 Y 個節點
最大連通分量的節點: a b c d ...
```

## 錯誤處理

程式包含以下錯誤處理機制：

1. **輸入驗證**：
   - 節點數量必須為正數
   - 邊數量不能為負數

2. **邊界檢查**：
   - 節點編號必須在 0 到 n-1 範圍內

3. **自環處理**：
   - 自動忽略自環邊（u == v 的情況）

3. **清晰的輸出格式**：以易讀的方式呈現結果
4. **高效的演算法**：使用 DFS 實現線性時間複雜度
