## 題目描述

### 請列表比較以下五種搜尋方法(Sequential search, Binary search, Interpolation search, AVL tree 及 Hashing)的基本原理及優缺點

---
## 解析

| 方法                              | 基本原理                                                                 | 優點                                                                                                      | 缺點                                                                                         |
|-----------------------------------|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------|
| **順序搜尋 (Sequential Search)**  | 依序從頭到尾檢查每個元素，直到找到目標或掃描完畢。                         | - 實作簡單<br>- 無須事先排序或額外資料結構<br>- 資料量小／查詢次數少時效能可接受                        | - 時間複雜度 O(n)，資料量大時效能差<br>- 平均需掃描 n/2 個元素                                 |
| **二分搜尋 (Binary Search)**      | 在已排序陣列中，比較中間元素並將搜尋範圍減半，直到找到或範圍為空。        | - 時間複雜度 O(log n) 快速<br>- 實作相對簡單                                                        | - 需有隨機存取的已排序資料結構<br>- 動態插入／刪除成本高                                      |
| **插值搜尋 (Interpolation Search)**| 根據目標值與範圍值的比例，估算可能位置並跳轉檢查，類似「尋找電匯位置」。 | - 平均時間 O(log log n)（資料分佈均勻時）<br>- 大範圍且分佈均勻時，比二分搜尋更高效                | - 最壞時間 O(n)，分佈不均勻時退化<br>- 需排序且估算位置需額外運算                              |
| **AVL 樹 (AVL Tree)**              | 自平衡二元搜尋樹，透過單／雙旋轉保持任一節點之左右子樹高度差 ≤ 1。        | - 動態插入／刪除後仍維持 O(log n) 搜尋<br>- 適合頻繁更新的資料結構                                        | - 節點需儲存高度資訊，記憶體開銷較大<br>- 插入／刪除需旋轉，實作較複雜                           |
| **雜湊 (Hashing)**                 | 透過雜湊函式將關鍵值映射到陣列索引，直接存取對應 bucket。         | - 平均 O(1) 查找速度<br>- 支援大規模資料庫與快速存取                                                   | - 需處理碰撞，最壞 O(n)<br>- 不保證元素有序<br>- 需額外空間及良好雜湊函式以降低碰撞率            |
